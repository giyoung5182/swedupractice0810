# 기존 현황판 주소의 호환 연결용 보관본

현황판의 화면 코드는 [incheonsw](https://github.com/giyoung5182/incheonsw)에서 관리합니다. 사용할 사이트는 https://incheonsw.vercel.app 입니다.

이 저장소에는 기존 주소 https://swedupractice0810.vercel.app 를 유지하기 위한 `vercel.json` 연결 설정만 둡니다. 별도의 현황판 화면 코드는 관리하지 않습니다.

## 연결 방식

모든 경로를 대표 사이트의 같은 경로로 HTTP 307 임시 연결합니다. 기존 수업 자료와 즐겨찾기의 링크를 끊지 않기 위한 설정입니다. 대표 사이트를 이 주소로 다시 연결하면 반복 이동이 생기므로 대표 사이트의 역방향 연결은 추가하지 않습니다.

외부 기록 API와 데이터·권한은 변경하지 않습니다. 이 저장소를 보관 상태로 전환해도 기존 Vercel 프로젝트와 도메인은 제거하지 않습니다.

## 원본과 복구

통합 전 화면 파일은 [기존 커밋의 index.html](https://github.com/giyoung5182/swedupractice0810/blob/0cb1e0cbc7c31a4fd5e074b2e0f5a9d004df30e0/index.html)에 남아 있습니다. 보관 해제 후 필요하면 해당 파일과 이전 설정을 Git 이력에서 복구할 수 있습니다.

2026-11-15 통합 전 두 사이트의 HTML과 외부 연결 주소가 같음을 확인했습니다. 앞으로 현황판 기능 수정은 관리 원본에서 진행하고, 이 저장소는 주소 호환 설정을 바꿀 때만 사용합니다.
